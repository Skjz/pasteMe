# PasteMe

仿照 [Paste](https://pasteapp.io) 的 macOS 剪贴板管理工具。常驻菜单栏，记下你复制过的每一样东西，按 ⇧⌘V 从屏幕底部呼出历史，选中后直接粘贴到当前应用。

## 功能（0.1.0）

- 后台记录复制的文本、链接、图片和文件，保存在本地 SQLite，不限条数。
- 复制图片文件时，卡片直接显示图片缩略图。缩略图在复制时保存，原文件之后移走或删除也能看到。
- 同一内容再次复制不会重复记录，只把原记录移到最前。
- 自动跳过密码管理器等应用标记为“敏感”或“临时”的内容（`org.nspasteboard.ConcealedType` 等）。
- 共享屏幕、录屏和截图时，别人看不到面板（包括预览窗口），本机屏幕上照常显示。需要录教程时，在设置窗口的「面板」页打开「共享屏幕时显示面板」。这依靠 macOS 的窗口共享设置，个别录屏工具可能不遵守。
- ⇧⌘V 在鼠标所在屏幕底部呼出横向卡片面板，卡片显示类型、来源应用和复制时间。卡片标题栏取来源应用图标的颜色。选中的卡片稍微放大，外面有一圈发光的光标，随选中项在卡片之间滑动；光标样式可以在设置窗口的「面板」页选「呼吸」或「流光」。面板从屏幕底部滑入、卡片依次出现，收起时向下滑出；开启系统的「减少动态效果」后只做淡入淡出。
- 面板快捷键。面板上的焦点在搜索框或卡片列表上：呼出面板时在卡片列表上，直接打字或按 ↑ 进入搜索框，按 ↓ 或点击卡片回到卡片列表。编辑文字的按键只在焦点所在的地方起作用，在搜索框里按 ⌘⌫ 不会删掉记录。

  | 按键 | 作用 |
  | --- | --- |
  | 直接输入 | 搜索文本内容、图片里的文字和来源应用的名字（中文名、英文名或你加的别名） |
  | @ | 弹出类型和来源应用的列表，接着输入可以缩小范围，↑ ↓ 选择、↩ 或 Tab 选中后按它筛选；esc 关掉列表，按文字搜索 `@` 开头的词 |
  | ← → | 选择卡片（焦点在搜索框且已输入文字时，移动文字插入点） |
  | ↓ / ↑ | 焦点移到卡片列表 / 搜索框 |
  | ↩ / 双击 | 粘贴到当前应用 |
  | ⇧↩ | 以纯文本粘贴（去掉格式） |
  | ⌘1 … ⌘9 | 粘贴从最左边一张完整显示的卡片数起的第 1 … 9 张，按住 ⇧ 时以纯文本粘贴。按住 ⌘ 片刻，卡片右下角会标出编号 |
  | ⌘⌫ | 焦点在卡片列表时，删除选中的条目：卡片碎成颗粒向上飘散，散完后右边的卡片补上来。在 Pinboard 里是把条目移出这个 Pinboard，条目还在历史里 |
  | ⌘Z | 焦点在卡片列表时，撤销删除或移出（面板关闭、切换标签前有效）：颗粒飘回来拼成卡片 |
  | 空格 | 焦点在卡片列表时，预览选中的条目；再按一次、按 esc 或点面板上的空白处关闭 |
  | ⌥← / ⌥→ | 预览几个文件的条目时，换着看上一个、下一个文件（搜索框里有文字时按词移动插入点） |
  | ⌘C | 焦点在卡片列表时，把选中的条目拷贝到剪贴板，不粘贴；面板不收起，关上面板后它移到历史最前 |
  | ⌘R | 焦点在卡片列表时，在选中卡片的标题栏里起标题、改标题，↩ 保存、esc 取消 |
  | ⌘E | 编辑选中的文本或链接 |
  | ⌘N | 新建一条文本 |
  | ⌘P | 固定到最近用过的 Pinboard（还没有 Pinboard 时先新建一个） |
  | ⌘← / ⌘→ | 在「历史」和各个 Pinboard 之间切换（焦点在搜索框且已输入文字时，把插入点移到行首、行尾）；面板开着时再按 ⇧⌘V 也会切到下一个 |
  | ⌘J | 在历史里查看：清空搜索和筛选，回到「历史」，选中这个条目 |
  | ⌘O | 打开选中的链接、文件或文件夹，面板收起：链接用默认浏览器，文件用默认的应用，文件夹用访达。文件和文件夹的打开方式可以在设置窗口的「面板」页分别改成 Visual Studio Code、Cursor 或终端（终端、iTerm2、Ghostty、Otty），用终端打开文件时打开它所在的文件夹。右键菜单里有「打开」，文件卡片还有「打开方式」，随时选一个装了的应用 |
  | esc | 清空搜索词和筛选，焦点回到卡片列表；再按一次关闭面板 |

- Paste Stack：按 ⌃⇧⌘C（或在菜单栏菜单里选「Paste Stack」）后依次复制几段内容，再到目标应用里每按一次 ⌘V，就按复制的顺序粘贴下一条，粘完自动退出。屏幕右上角的小浮窗列出等待粘贴的条目，标出下一条；鼠标移到某一行上可以把它拿掉。按 esc、再按一次 ⌃⇧⌘C 或点浮窗的关闭按钮随时退出，之后 ⌘V 恢复正常。复制的内容照常进入历史，粘贴时不会重复记录。需要辅助功能权限；暂停记录时不能开启。
- 复制图片或图片文件后，几秒内会在本机识别出其中的中英文文字，截图也能按文字搜到。识别出文字的图片卡片上有一个小图标；搜索命中图片里的文字时，卡片底部显示命中的那一段。以前复制的图片会在启动后逐张补做识别。
- 来源应用的中文名和英文名都能搜到：访达的条目搜「finder」也能找到，微信的条目搜「wechat」也能找到，`app:` 后面也一样。名字从应用自己的本地化信息里读，不用手动设置。还可以给应用加自己的别名（比如给微信加「wx」）：在设置窗口的「应用别名」页里填，或者在卡片上右键选「为“微信”设置别名…」直接跳到这个应用。
- 搜索栏旁边可以按类型（文本、链接、图片、文件，可多选）、来源应用和时间（今天、昨天、最近 7 天、最近 30 天）筛选。在搜索框里输入 `@` 会列出类型、文本子类型和来源应用，接着输入的文字按类型的中英文名、应用的名字和别名缩小范围（例如 `@图`、`@wx`、`@finder`、`@base64`），选中后和点筛选按钮一样；`a@b.com` 这种词中间的 `@` 不会弹出列表。也可以直接输入 `type:图片`（或 `type:image`、`type:im`）和 `app:微信`。筛选条件之间、和搜索词之间同时生效；没有结果时会列出是哪些条件。每次呼出面板时清空。
- 全局快捷键（⇧⌘V 呼出面板、⌃⇧⌘V 暂停记录、⌃⇧⌘C 开启 Paste Stack）可以在设置窗口的「通用」页重新录制：点一下快捷键再按下新的组合，esc 取消，⌫ 清除，改了马上生效。组合要带 ⌘、⌃ 或 ⌥；和另一项重复、和系统快捷键相同时会说明原因，不保存。和其他应用的快捷键冲突查不出来，改完按一下试试。和面板里的按键相同时（比如 ⌘P）也能保存，但会提醒面板里那个功能用不了。菜单栏菜单和屏幕上的提示显示的都是新的组合。
- 暂停记录：按 ⌃⇧⌘V 立即暂停，再按一次恢复；也可以在菜单栏菜单里暂停 5 分钟、30 分钟或 1 小时，到时自动恢复。暂停时菜单栏图标带一道斜杠，切换时屏幕上会短暂提示。重启应用后总是从记录状态开始。
- 复制时播放提示音（默认关闭）：在设置窗口的「通用」页打开（打开时先响一次），之后每记下一次复制就响一声 PasteMe 自己的提示音：一张纸滑进剪贴板的夹子，「嗒」地夹住。4 个略有不同的版本轮流播放，像真的纸每次都不太一样。再次复制历史里已有的内容也响。暂停记录时、密码之类不保存的内容、PasteMe 自己写进剪贴板的内容（从面板粘贴、⌘C 拷贝卡片、Paste Stack）都不响。关掉「系统设置 → 声音」里的「播放用户界面音效」后也不响。剪贴板每半秒检查一次，所以提示音最多比 ⌘C 晚半秒。
- Pinboard：把常用的条目固定到自建、有名字和颜色的分组里。面板左上角的标签在「历史」和各个 Pinboard 之间切换（点击、⌘← ⌘→，或面板开着时再按 ⇧⌘V）。选中卡片按 ⌘P 固定到最近用过的 Pinboard，也可以在右键菜单的「固定到」里勾选，或者把卡片拖到标签上。Pinboard 里的卡片按你排的顺序显示，拖到别的卡片上就换位置；⌘⌫ 只是把条目移出这个 Pinboard。点 + 新建，双击标签改名字，右键标签改颜色或删除（删除前会确认，里面的条目还留在历史里）。在历史里，固定过的卡片底部有个图钉。清空历史时固定的条目会保留，顺序也不变。
- 按 Pinboard 筛选：时间筛选旁边的 Pinboard 菜单可以选一个或几个，也可以输入 `@` 从列表里选。搜索和其他筛选在 Pinboard 里也能用。⌘J 或右键菜单里的「在历史里查看」跳回历史里这个条目的位置，看到前后复制的内容，早于面板平时显示的 200 条也可以。
- 预览：选中卡片按空格，面板上方弹出预览，显示长文本的全部内容（保留格式）、可以缩放的原图（触控板捏合或右上角的按钮）、链接的网页，文件用系统的 Quick Look 显示。窗口顶上一条窄栏，左边是标题（没起标题时写网站、文件名或字数，点进去就能起标题），右边是这种内容的几个按钮和关闭，颜色很淡，鼠标移进来才深一点；下面全是内容，没有分隔线，控件不会挡住内容。网页、PDF 这类文件和大图用面板上方的大部分地方（最宽是屏幕的 80%），图片保持原来的比例，文本和代码文件按行数定高度，文件夹是一个小窗口。一次复制了几个文件时，顶栏右边是「‹ 文件名 2 / 3 ›」：点箭头或按 ⌥← ⌥→ 换着看，点文件名从列表里选。预览开着时 ← → 换到旁边的卡片（点别的卡片也一样），↩ 直接粘贴，点面板上的空白处（卡片之间的空隙、搜索栏那一行的空隙）关掉预览。图片预览下方列出识别出的文字，可以一键拷贝。
- 预览网页：链接卡片的预览直接显示网页，可以滚动，顶栏右边有「在浏览器中打开」。按空格就会打开网页、执行网页里的脚本，这和「链接预览」设置无关；网页不带登录信息（Cookie），关掉预览就清掉，不写到磁盘，声音和视频不自动播放。看起来像一次性的链接（网址里有 token、reset、verify 这类词）先不打开，点「加载网页」才打开。预览开着时按 ← → 换到别的链接，在一张卡片上停 0.3 秒才开始加载，按住方向键快速经过的不加载。在网页里点链接用默认浏览器打开，预览里的页面不变；要下载的文件不在预览里下载。要改网址时按 ⌘E。
- 编辑和标题：点进预览的正文（或按 ⌘E、右键「编辑…」）就能改文本和链接，关闭预览时保存，之后搜索和粘贴都用改过的内容。改完和另一条内容相同时合并成一条，保留较新的时间。可以给任何条目起标题：选中卡片按 ⌘R 或右键「添加标题」，直接在卡片标题栏里输入，也可以在预览顶部输入；卡片上显示标题，类型挪到第二行的时间前面（例如「文本 · hex · 4 分钟前」），搜索也能搜到。⌘N 新建一条文本，在 Pinboard 里新建的直接固定在这里。
- 链接预览（默认关闭）：在设置窗口的「链接预览」页选一档，每一档会请求什么写在选项下面。「只取网站图标」只打开网站的首页，卡片上显示网站图标；你复制的网址本身不会被打开，所以不会让任何链接失效。「完整预览」会打开复制的网址，卡片上显示网页标题、预览图和网站图标，搜索也能搜到网页标题；看起来像一次性的链接（网址里有 token、reset、verify、login 这类词，或者一长串像令牌、签名、UUID 的随机字符），以及跳转到这类网址的短链接，仍然只取网站图标。网页只读 HTML，不执行脚本，不带也不存 Cookie，不下载安装包这类文件。本机和内网的地址（localhost、`.local`、私有网段和 Tailscale 的地址、没有点的主机名）不会请求，以前复制的链接也不会补做；获取失败的链接保持原样，不反复重试。Reddit 的网页不用浏览器打不开，帖子标题改从它的 oEmbed 接口取，版块和分享短链显示版块名（比如 `r/swift`）。分享时附带的跟踪参数（`utm_…`、`si`、`share_id` 等）会先去掉，YouTube、Reddit 的分享链接也能拿到完整预览。有预览的链接卡片是海报式的排版：居中，网页标题用衬线字体（英文 New York、中文宋体），下面是字距拉开的网站名，夹在两条细线中间；上面是预览图，没有预览图时是放大的网站图标，带一圈图标颜色的光。没有网页标题时从网址读出标题，比如 GitHub 仓库显示「swiftlang / swift」，维基百科词条显示「Swift」。其他需要浏览器才能打开的网站（比如知乎）拿不到预览。很短、又没有上面那些特征的一次性链接认不出来，在意的话请选「只取网站图标」。
- 拖出卡片：把卡片拖到其他应用里，文本和链接作为文字（文本拖到访达里是一个 .txt 文件），文件就是原来的文件，图片同时给出图片数据和一个 PNG 文件，访达、网页上传框和只收文件的聊天窗口也能用。拖出面板时面板自动收起，不挡住要放下的地方。图片卡片的右键菜单里有「以文件粘贴」，在访达里粘贴会得到一个 PNG 文件；在设置窗口的「面板」页打开「图片以文件粘贴」后，粘贴图片总是带着文件。从面板把文本粘贴到访达时，当前文件夹里会多出一个 .txt 文件（UTF-8），文件名用标题，没有标题时用第一行，粘贴到其他应用时仍然是文字。图片文件以复制时间命名（例如 `PasteMe 2026-10-16 14.41.55.png`）。这些文件放在 `~/Library/Caches/PasteMe/Files`，一天没用就删除。
- 文本子类型：一段文字整段是颜色值（`#ff8800`、`rgb(255, 136, 0)`、`hsl(…)`）、Unix 时间戳（10 位秒、13 位毫秒）、`hexdump -C` 或 `xxd` 的输出（字符栏不带竖线、每行字节数不同的也算，比如抓包工具拷出来的）、hex 或 Base64 时，卡片标题栏显示「文本 · 颜色」「文本 · 时间戳」这样的子类型。颜色卡片显示色块和颜色值的另一种写法，hexdump、hex 和 Base64 用等宽字体。输入 `@时间戳`、`@颜色`、`@base64`、`@hex`、`@hexdump`、`@代码`（或 `type:base64`）只看这一种，按「文本」筛选时仍然包含它们。长段落里夹着的一小段、超过 1 MB 的内容不识别。升级前记下的文字会在启动后分批补算。
- 转换：时间戳卡片直接显示对应的本地时间、时区和相对时间（例如 `2025-10-17 16:00:00 GMT+8`、「去年」）。文本和链接卡片的右键菜单里有「转换」，选中卡片按 ⌘T 也能打开：任何文字都可以编码为 Base64；Base64 可以解码（解出来不是文字时改为转成 hex、hexdump）；hex 和 hexdump 可以互转，也可以转成 ASCII 文本（按 UTF-8 解码）和 `xxd -i` 那样的 C 数组；时间戳可以转成本地时间和 ISO 8601（UTC）。转换结果作为一条新的文本记录到历史最前面并选中，按回车就能粘贴，原来的条目不变；解码出来是网址时记成链接。
- 哈希值：「转换」菜单里还有 MD5、SHA-1 和 SHA-256，算的是文字本身（按 UTF-8，Base64、hex 不先解码）；文件卡片的右键菜单里有「计算 MD5」「计算 SHA-1」「计算 SHA-256」，算文件内容，几个文件时每行一个 `<哈希值>  <路径>`。结果和转换一样记到历史最前面。在后台计算，大文件不会卡住面板。
- 自动清除历史：在设置窗口的「历史」页选 7 天、30 天、90 天或 1 年（默认永不），超过这段时间没有再复制或粘贴过的条目会被删除，固定在 Pinboard 里的保留。启动时和之后每小时检查一次；选了马上就要删条目的时间时，会先说明删多少条。
- 代码高亮：认得出 Swift、Objective-C、C、C++、C#、Java、Kotlin、Go、Rust、JavaScript、TypeScript、Python、Ruby、PHP、Shell、SQL、HTML、XML、CSS、JSON、YAML 的代码，卡片标题栏显示语言（例如「文本 · Swift」），正文用等宽字体按关键字、字符串、数字、注释、类型名、函数调用等着色，颜色跟 Xcode 的默认主题一样，随浅色、深色外观切换。保留缩进（去掉各行共同的缩进，tab 按 4 个空格），长行在卡片右边截断、不换行。拿不准时当普通文字：普通段落、Markdown、邮件、聊天记录不会被当成代码；从 Xcode、VS Code、JetBrains 等编辑器和终端复制的内容更容易认出来，终端里复制的一行命令也算 Shell。粘贴时仍然是原来的文字。
- 检查更新：每天向 GitHub 查一次有没有新版本，请求里不带任何内容，可以在设置的「关于」页关掉。有新版本时菜单栏菜单最前面出现「更新到 PasteMe x.y.z…」，屏幕下方提示一次，不弹窗打断你。点了安装才下载，小窗口里显示下载进度，可以取消；下载的安装包要有发布者的签名才会安装（防止被人换掉），装好后 PasteMe 自己重新打开。菜单栏菜单的「检查更新…」和「关于」页的「立即检查」可以手动查。
- 菜单栏菜单只放常用的操作：打开历史、暂停记录、Paste Stack、检查更新…、设置…（⌘,）和退出；没有辅助功能权限时最前面多一项提醒，有新版本时多一项更新。
- 设置窗口：左边侧栏选页，右边是分组的开关，大小固定。「通用」有登录时启动、复制时播放提示音、辅助功能权限和全局快捷键；「面板」有光标样式、共享屏幕时显示面板、图片以文件粘贴，以及文件和文件夹的打开方式；「链接预览」选获取哪一档；「历史」有自动清除和清空历史（保留 Pinboard）；「应用别名」给来源应用加别名；「关于」是版本号、检查更新和项目主页。

## 安装

需要 macOS 14 及以上，Apple 芯片和 Intel 的 Mac 都能用。

1. 从 [Releases](https://github.com/Skjz/pasteMe/releases) 下载最新的 `PasteMe-<版本>.dmg`，打开后把 PasteMe 拖进「应用程序」。
2. 第一次打开时系统会拦下：PasteMe 没有经过 Apple 公证。关掉提示框，到「系统设置 → 隐私与安全性」，在「安全性」下面找到 PasteMe，点「仍要打开」并确认。也可以在终端里运行下面这行，去掉下载标记后正常打开：

   ```bash
   xattr -dr com.apple.quarantine /Applications/PasteMe.app
   ```

3. 在「系统设置 → 隐私与安全性 → 辅助功能」里允许 PasteMe，否则只能写入剪贴板，不能直接粘贴（见下面的「辅助功能权限」）。

有新版本时 PasteMe 会在菜单栏菜单里提示，点「更新到…」就能装好并重新打开（从 0.1.0 升上来要手动下载一次）。手动升级时先退出 PasteMe，再用新版本替换「应用程序」里的旧版本。发布版用的是临时签名，每次升级后都要在「辅助功能」里删掉旧的 PasteMe 条目，再重新允许。

## 构建和运行

需要 macOS 14 及以上、Xcode 16 及以上（Swift 6）。

```bash
scripts/bundle.sh
```

```bash
open build/PasteMe.app
```

`scripts/bundle.sh` 编译 release 版本，打包成开发版 `build/PasteMe.app`（名字是 PasteMe Dev，见下面的「数据位置」）并签名。默认使用钥匙串里第一个 “Apple Development” 证书；没有证书时用临时签名。发布用的 DMG 由 `scripts/make-dmg.sh` 打包，步骤见 [docs/architecture.md](docs/architecture.md) 的「发布」。

### 辅助功能权限

PasteMe 通过模拟按下 ⌘V 把内容粘贴到当前应用，这需要在「系统设置 → 隐私与安全性 → 辅助功能」里允许 PasteMe。没有授权时，选中的内容仍会写入剪贴板，手动按 ⌘V 即可。

自己用 `scripts/bundle.sh` 打包的是开发版「PasteMe Dev」，在辅助功能里和发布版的 PasteMe 是两项，要分别允许。用固定证书签名时，重新编译后权限保持有效；用临时签名（`PASTEME_SIGN_IDENTITY=-`）则每次重新编译都要在设置里删掉旧条目再重新授权。

### 数据位置

历史和 Pinboard 保存在 `~/Library/Application Support/PasteMe/history.sqlite`。删除这个文件即清空全部历史和 Pinboard。以文件粘贴、拖出图片时生成的临时文件在 `~/Library/Caches/PasteMe/Files`，可以随时删除。设置存在偏好域 `io.github.skjz.PasteMe` 里。

开发版（`scripts/bundle.sh` 打的 PasteMe Dev、`swift run`、基准和测试）用的是另一套：历史和缓存在 `PasteMe Dev` 目录，设置在 `io.github.skjz.PasteMe.dev`，开发时启动的测试实例碰不到你在用的 PasteMe（ADR 0009）。

## 开发

```bash
swift test
```

```bash
swift run PasteMe
```

- `Sources/PasteMeCore`：与界面无关的部分，包括数据模型、SQLite 存储、查询条件（`ClipQuery`）、粘贴流程（`Paster`）、设置（`Settings`）、剪贴板内容的读写转换。测试在 `Tests/PasteMeCoreTests`。
- `Sources/PasteMeApp`：菜单栏应用本体，包括剪贴板轮询、全局快捷键、发送 ⌘V、面板和卡片视图。做成库是为了让面板逻辑也能测试，测试在 `Tests/PasteMeAppTests`。
- `Sources/PasteMe`：可执行文件，只有 `main.swift`，负责启动 `PasteMeApp` 里的 `AppDelegate`。
- 调试构建可以把面板渲染成图片后退出，用于在没有屏幕录制权限时检查界面：

  ```bash
  PASTEME_SNAPSHOT=/tmp/panel.png swift run PasteMe
  ```

  再加上 `PASTEME_SNAPSHOT_QUERY='type:图片 报销'` 会先在搜索框里输入这段文字，用来检查筛选和搜索结果；加上 `PASTEME_SNAPSHOT_DELETE=1` 会先删除选中的卡片，用来检查删除后其他卡片有没有移动。`PASTEME_SNAPSHOT_TAB=1` 切到第一个 Pinboard；`PASTEME_SNAPSHOT_PREVIEW=1`、`PASTEME_SNAPSHOT_EDITOR=1` 打开预览窗口、新建 Pinboard 的窗口，另存为 `<文件名>-preview.png`、`<文件名>-editor.png`；`PASTEME_SNAPSHOT_APPEARANCE=light` 或 `dark` 不管系统设置，按浅色或深色外观画。
